# TeacherDesk

A teacher-first academic workflow assistant designed to help teachers plan, organize, track, and manage their daily teaching work from one place.

## 🚀 Live Demo

**[Open TeacherDesk](https://teacherdesk.freebuff.app/dashboard)**

## ✨ Features

* 📊 **Dashboard** — See important teaching work and priorities at a glance
* ✅ **Task Management** — Create, organize, complete, edit, search, and filter tasks
* 📚 **Lesson Planner** — Plan lessons with subjects, classes, topics, objectives, activities, materials, homework, and notes
* 📝 **Corrections Tracker** — Track papers to be corrected, deadlines, progress, and completion
* 📄 **Question Paper Preparation** — Organize exam preparation, syllabus topics, marks, duration, deadlines, and status
* 🕐 **Timetable** — Manage teaching schedules and detect timetable conflicts
* 🪑 **Exam Seating** — Create seating plans, assign students to seats, auto-arrange students, and manage capacity
* 🕘 **Activity History** — Keep track of important actions performed in the application
* 👤 **Teacher Profile & Settings** — Manage personal preferences and account data
* 🔐 **Authentication** — Secure user accounts and user-owned data
* 📱 **Mobile-First Design** — Designed to work comfortably on phones as well as desktop screens

## 🎯 Why TeacherDesk?

Teachers often manage tasks, lesson planning, corrections, exam preparation, timetables, and seating arrangements across multiple tools.

**TeacherDesk brings these everyday workflows together into one focused workspace.**

The goal is simple:

> **What do I need to prepare, complete, review, or remember today?**

## 💻 Getting Started

### Prerequisites

* [Bun](https://bun.sh/)
* A configured Convex environment

### Installation

```bash
git clone https://github.com/advith-crypto/TeacherDesk.git
cd TeacherDesk
bun install
```

Configure the required environment variables for the frontend and Convex backend, then start the development environment using the project's configured Bun/Convex workflow.
